# 旅行青蛙 · 我的游戏账号纪念档案

这是我在《旅行青蛙·中国之旅》中留下的个人游戏记录。为了在停服前尽可能保留这段游玩经历，我将自己手机中能够读取的明信片、分享图片和图片上的文字整理成一份可以离线浏览的纪念档案。

档案以我的游戏图片为主体，另附从游戏资源中整理出的通用素材图鉴。它保存的是目前能够取得的图片和信息，属于**部分数据存档**，不能用于恢复账号、还原完整游戏进度或继续游玩。

## 查看档案

- 在线浏览：[我的旅行青蛙时光胶囊](https://moonpie0.github.io/frog-time-capsule/GameTimeCapsule/viewer/)
- 本地浏览：打开 [GameTimeCapsule/viewer/index.html](GameTimeCapsule/viewer/index.html)，无需安装软件或启动服务器。

页面可以查看明信片、图鉴与收藏、资源图鉴、道具资料、贴纸分享、活动图片、旅行汇总和个人资料，并支持图片搜索、筛选、放大预览及关联图片查看。左侧“不倒翁”提供独立的部件拼装体验。本地文件修改后，需要同步到 GitHub 并完成 Pages 部署，在线页面才会更新。

离线保存时请下载整个 `GameTimeCapsule` 文件夹，保留目录结构。只保存 HTML 文件会缺少图片。

## 数据是怎样获取的

### 1. 从自己的 Android 手机复制游戏分享图片

通过 USB 连接手机，在本人授权 USB 调试后，使用 **ADB + Python 本地备份工具**读取游戏专属外部目录中可访问的分享图片：

```text
/sdcard/Android/data/com.aligames.lxqw.hhb/files/umeng_cache/
```

只复制经过筛选的游戏图片，记录来源路径、可取得的文件时间、文件大小和 SHA-256。图片传输前后进行校验，保留原始文件，不对原图重新编码或有损压缩。

完全相同的图片通过 SHA-256 和逐字节比较去重，只保留一份原图，同时保留每份副本的来源记录。画面相似但日期、文字、边框或文件内容不同的图片分别保存。

### 2. 在电脑上识别、核对图片信息

使用 **Windows 本地 OCR**识别图片中的文字，再结合图片进行分类和可见信息核对。整理内容包括图片上的日期、地点、署名、物品名称和说明；OCR 原文与整理后的字段分开保存，便于追溯。

图片日期仅表示图片中印出的日期，没有被当作真实出发时间、获得时间或服务器记录。图片署名也没有被当作已确认的账号昵称或 UID。

### 3. 从 MIUI 系统备份中整理通用素材

在手机上使用 **MIUI 系统本地备份**备份目标游戏，再通过电脑只读检查备份目录，按需读取其中未加密的静态图片和图集索引。使用 **Python + Pillow**按照图集坐标裁切，导出无损 PNG，并保留图集原件、坐标、资源编号及校验信息。

这些素材构成页面中的“资源图鉴”。有个人分享图可以对应的资源，补充图片中可确认的名称、说明或关联入口；其余使用原始资源编号。

通用资源只说明游戏包含这些素材，**不代表我的账号已经拥有或解锁它们**。系统备份整包及本地检查工作文件不随网页发布。

### 4. 还原不倒翁静态图片

在本人追加授权后，从同一 MIUI 备份的安装包中按清单读取 58 个不倒翁静态图片文件，并在电脑上使用客户端兼容的 **XXTEA 图片解码方法**还原为透明 PNG。逐张验证 PNG 完整性、尺寸和透明通道，记录解码前后的 SHA-256，保留原始密文和本地处理记录。

解码对象仅为通用图片素材，没有读取账号运行时参数、登录信息或支付数据。网页中只包含已转换的图片和展示资料，不包含图片密钥、客户端解密代码或系统备份整包。通用配置包仍未解密。

### 5. 生成本地 HTML 档案

将原图、整理后的 JSON 信息和资源图片组织为静态 HTML 页面。页面无需后端、数据库或外部脚本，本地打开时不依赖网络。备份、OCR 和整理过程在本地完成；GitHub Pages 用于展示另外发布的网页与图片。

在“不倒翁”页面可以切换部件、调整位置和大小、旋转及翻转、改变底色、随机组合、撤销重做，并保存 800 × 800 透明 PNG。底图自动匹配同编号遮罩；组合保存在当前浏览器的本地存储中，存储不可用时会提示。拼装结果是独立创作，不代表我的账号实际拥有或在游戏中保存过这一组合。

原始尺寸的还原图片在 `media/tumbler/`，来源和 SHA-256 在 `parsed/tumbler-catalog.json`。生成 HTML 时校验全部 58 张图片，再将它们嵌入页面，使离线打开时也能正常导出组合图片。

## 文件组织

```text
GameTimeCapsule/
  viewer/         离线 HTML 页面
  raw/            去重后保留的个人游戏原图
  media/          通用资源图集、索引、裁切图片和不倒翁部件
  parsed/         图片信息、OCR 原文、分类资料和资源清单
  screenshots/    后续人工补充的游戏截图
  reports/        备份、整理及完整性检查记录
  manifest.json   原始文件与来源清单
```

网页已隐藏数据地图、原件校验视图及侧栏中的备份报告入口，相关文件仍保留用于核对。隐藏入口不等于文件不可访问；公开仓库中已提交的文件仍可通过仓库或对应地址查看。

## 备份原则

仅整理本人设备和本人账号相关数据。未使用 Root、越狱、进程注入、Hook、系统沙盒绕过或网络抓包；未读取或导出登录密码、Cookie、Token、支付凭证和设备密钥。不倒翁静态图片的本地解码经过本人追加授权，范围限于上述通用素材。遇到无法在允许范围内读取的内容，记录限制，不把未知数据编造成已保存内容。

原始图片与来源记录用于个人留存和核对。游戏名称及游戏画面、资源素材的相关权利归各自权利人所有；本项目为个人纪念档案，与游戏官方无关。
